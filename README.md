# SnapDance — танец из фото для TikTok

Клиент загружает до 3 фото, выбирает трендовый танец (по ролику-образцу) или стиль и получает вертикальное видео 9:16, как снятое на телефон. Оплата — рубины через Stripe. Ключ fal.ai хранится только на сервере, клиент цен в долларах не видит.

## Файлы (все кладутся в корень репозитория, без папок)

| Файл | Что это |
|---|---|
| `server.mjs` | весь сервер одним файлом: генерация, оплата, рубины, админка |
| `index.html` | сайт и студия для клиента (с телефона и компьютера) |
| `admin.html` | админка: `/admin` |
| `Dockerfile` | сборка для Railway: Node 20 + ffmpeg (обработка «как с телефона») |
| `package.json` | описание проекта |

## Запуск на Railway через GitHub

1. Создайте на GitHub **новый** репозиторий (например, `snapdance`) и загрузите в корень эти 6 файлов.
2. Railway → **New Project → Deploy from GitHub repo** → выберите репозиторий. Railway увидит `Dockerfile` и соберёт по нему сам.
3. **Volume** (обязательно — там рубины клиентов, заказы и видео): правый клик по сервису → **Attach volume** → путь `/data`.
4. **Settings → Networking → Generate Domain** — получите адрес сайта.
5. **Variables**:

| Переменная | Значение |
|---|---|
| `FAL_KEY` | ваш ключ fal.ai (лучше новый — старый был в чате) |
| `ADMIN_PASSWORD` | пароль для `/admin` |
| `PUBLIC_URL` | адрес сайта из шага 4, например `https://snapdance.up.railway.app` (без `/` в конце). Нужен, чтобы fal.ai скачивал фото и ролики клиентов |
| `STRIPE_SECRET_KEY` | `sk_live_…` из Stripe → Developers → API keys |
| `STRIPE_WEBHOOK_SECRET` | `whsec_…`, см. ниже |
| `CONTACT_EMAIL` | (по желанию) почта поддержки в подвале сайта |

6. **Вебхук Stripe** — чтобы рубины начислялись даже если клиент закрыл страницу после оплаты: Stripe → Developers → Webhooks → **Add endpoint**
   - URL: `https://ВАШ-АДРЕС/api/stripe/webhook`
   - события: `checkout.session.completed` и `checkout.session.async_payment_succeeded`
   - скопируйте **Signing secret** в `STRIPE_WEBHOOK_SECRET`.
7. Проверка: откройте `https://ВАШ-АДРЕС/api/health` — должно быть «Ключ принят», «ffmpeg: есть», Stripe «подключён», «сохраняется».

## Первые шаги

- `/admin` → «Коды клиентов» → создайте себе код, например на 300 рубинов. На сайте: «Купить» → «уже есть код?» → введите код.
- Сделайте пару видео в «Эконом», потом в «ТОП» — сравните.
- `/admin` → «Пакеты и цены»: цена в рубинах считается **автоматически** = себестоимость fal.ai × наценка (по умолчанию ×3 + 10% запаса на неудачные генерации). Рубин оценивается по самому выгодному пакету за вычетом комиссии Stripe (4% + 0,30 с запасом) и НДС, если он есть, — поэтому наценка соблюдается при любом пакете. Внизу таблица-проверка: сколько платит клиент, сколько остаётся вам и реальная наценка.
- Если вы плательщик НДС/IVA и цены пакетов его включают — впишите ставку (например, 21) в поле «НДС / IVA в цене».
- Если fal.ai поменяет цены — обновите себестоимость моделей в том же разделе, рубины пересчитаются сами.

## Примеры «до и после» на главной

`/admin` → «Примеры до/после»: загрузите фото «до» и видео «после», добавьте подпись — пример сразу появится на главной под баннером (видео играет само, фото «до» — в углу). Порядок меняется стрелками, пример можно скрыть или удалить. Ещё быстрее: вкладка «Видео» → у готового видео кнопка «⭐ В примеры». Показывайте только тех, кто дал согласие (или себя).

## Как работает для клиента

1. Загружает фото (до 3) → отмечает согласие и 18+.
2. «Повторить тренд» (свой ролик-образец до 30 сек, есть кнопка поиска трендов в TikTok) или «По стилю».
3. Нажимает «Сделать танец». Если рубинов нет — открывается покупка, после оплаты сайт показывает личный код `SD-…` (его стоит сохранить), фото и настройки сохраняются.
4. Видео делается на сервере 3–8 минут — страницу можно закрыть, оно появится в «Мои видео».
5. Если генерация не удалась — рубины возвращаются автоматически. Если не сработал отдельный шаг (face-lock или 1080p) — возвращается его стоимость.

## Цепочка генерации на сервере

первый кадр по теме (Nano Banana) → танец (Kling Motion Control / Hailuo / Kling / Veo) → face-lock (видео-face-swap по фото) → Topaz 1080p + 60 кадров → ffmpeg: обрезка застывшего начала, вид «недорогой Android / старый айфон», оригинальный звук тренда.

Фото и ролики-образцы клиентов автоматически удаляются через 3 дня, готовые видео хранятся на Volume.

## Реклама, удержание и поиск

- **Аналитика.** Сайт отправляет события в GA4, TikTok и Meta (ID пикселей — в `/admin` → «Маркетинг»): время на странице (10/30/60/120 с), прокрутку, клики, загрузку фото, начало оплаты, покупку с суммой, запуск генерации.
- **Удержание.** Пока видео делается, во вкладке виден процент; когда готово — заголовок «✅ ¡Tu vídeo está listo!» и уведомление браузера, если вкладка свёрнута.
- **Языки.** `/` — испанский, `/en`, `/ru`; при первом заходе человека переводит на язык его телефона, ботов — нет. Старые `?lang=` перенаправляются.
- **Поиск и ИИ.** Каждая версия отдаётся уже переведённой; `hreflang`, `canonical`, разметка WebApplication с ценами и FAQPage; `sitemap.xml`; `robots.txt` пускает Google, Bing и ИИ-ботов и закрывает видео клиентов; `/llms.txt`.
- **Доверие.** Блок частых вопросов, «Пакеты от …» под кнопкой, страницы `/privacy` и `/terms` (и `/en/…`, `/ru/…`) — их проверяют TikTok и Meta при модерации рекламы.
- **Скорость.** Для примеров на главной автоматически делаются лёгкие копии (видео 540p, фото 480 px); HTML сжимается.

## Рекламный ролик из примера

`/admin` → «Примеры до/после» → у примера блок «🎬 Рекламный ролик»: выберите язык (испанский, английский, русский) и голос и нажмите «Сделать ролик». Через 1–2 минуты появится вертикальное видео 1080×1920 (~14 с) для TikTok, Reels и Shorts:

1. фото «до» с вопросом-крючком («¿Solo tienes una foto?»),
2. готовый танец с подписью «La IA la convierte en un baile de tendencia»,
3. финальный экран: «¿Quieres bailar tú también?», **snapdance.us**, «Enlace en el perfil o búscalo en Google».

**Текст ролика:** «Стандартный» (один ролик на язык) или «✨ Новый текст от ИИ» — каждый раз новый вариант крючка, подписей, голоса и текста для публикации с другим подходом (юмор, вызов, интрига, до/после, «все уже делают», история, «без съёмки», подарок). Без обещаний просмотров и денег. Все варианты хранятся рядом — удобно для A/B-тестов; лишние можно удалить. Модель текста — `AD_LLM_MODEL` (по умолчанию Gemini 2.5 Flash через fal.ai). Длинные фразы автоматически переносятся по строкам.

Голос за кадром — ElevenLabs через fal.ai (≈ 2 цента за ролик), звук танца приглушён под голос. Без сердечек и интерфейса соцсетей. Рядом — готовый текст для публикации с хэштегами (кнопка «Копировать»). Адрес на ролике меняется переменной `AD_SITE`.

## ИИ-персонажи (блогеры-танцоры)

`/admin` → «ИИ-персонажи». Вымышленный совершеннолетний персонаж с уникальной футуристичной внешностью для своих аккаунтов:

1. **Создать 4 варианта** — имя, кто (девушка / парень / андрогинный образ) и пожелания к внешности. Остальные черты (волосы, глаза, особые приметы, одежда) подбираются случайно, пожелания важнее.
2. **Выбрать** вариант — создаётся «паспорт внешности»: фото в полный рост, лицо анфас и лицо 3/4, у каждого кнопка «Скачать».
3. Видео с персонажем делаются на сайте как обычно: загрузите эти 3 фото в 3 окошка — лицо будет одинаковым во всех роликах.

Себестоимость: варианты ≈ $0.60, паспорт ≈ $0.45. Модели меняются переменными `CHAR_T2I_MODEL` и `CHAR_EDIT_MODEL`. В TikTok/Instagram ролики с персонажем нужно отмечать как созданные ИИ.
