# SnapDance для iOS

Нативное приложение на SwiftUI (iOS 16+) для https://snapdance.us — без WebView. Работает с тем же сервером, что и сайт:
те же коды `SD-…`, рубины и видео. Сайт приложение не меняет.

## Что умеет

- Фото человека (в полный рост + по желанию лицо крупно и другой ракурс) из галереи.
- Ролик с трендом из галереи: любой длины, приложение само обрезает его до первых 15 секунд.
- Одна цена: Kling 2.6 + первый кадр Nano Banana Pro (как на сайте), цена считается по длине ролика.
- Ход создания с прогрессом, готовое видео по кругу, «Сохранить в Фото», «Поделиться», «Опубликовать в TikTok»
  (подпись копируется, открывается меню «Поделиться» с файлом — выбираете TikTok).
- «Мои видео» (хранятся 7 дней), удаление свайпом.
- Рубины через **покупки в App Store (StoreKit 2)**. Сервер проверяет подпись Apple и начисляет рубины на код `SD-…`;
  при первой покупке код создаётся автоматически. Можно войти своим кодом с сайта.
- Языки: испанский, английский, русский (по языку телефона).
- Ссылки на конфиденциальность, условия и жалобу на видео.

## Запуск

1. Откройте `SnapDance.xcodeproj`.
2. Проект **SnapDance** → цель **SnapDance** → **Signing & Capabilities** → **Team**: ваша команда разработчика.
   Bundle ID — `us.snapdance.app` (если меняете, поменяйте и переменную `IOS_BUNDLE_ID` в Railway).
3. Там же нажмите **+ Capability → In-App Purchase**.
4. Выберите iPhone или симулятор и нажмите ▶︎.

## Покупки в App Store Connect

В App Store Connect → ваше приложение → **Monetization → In-App Purchases** создайте три товара типа **Consumable**:

| Product ID | Рубинов | Цена (как на сайте) |
|---|---|---|
| `us.snapdance.app.rubies.start` | 200 | 14,99 € |
| `us.snapdance.app.rubies.pop` | 600 | 39,99 € |
| `us.snapdance.app.rubies.pro` | 1500 | 89,99 € |

Количество рубинов берётся с сервера (пакеты из админки сайта), цены — из App Store.
Проверить покупки можно через **TestFlight** или тестовый аккаунт Sandbox: сервер принимает и боевые, и тестовые покупки Apple.
Локальный файл StoreKit в Xcode для проверки не подходит: Apple подписывает такие покупки не своим сертификатом, и сервер их отклонит.

## Сервер

- `GET /api/iap/products` — список товаров и сколько рубинов в каждом.
- `POST /api/iap/verify` — принимает подписанную транзакцию StoreKit 2 (JWS), проверяет цепочку до Apple Root CA – G3,
  bundle ID и товар, начисляет рубины один раз на транзакцию.
- Railway → Variables, необязательно: `IOS_BUNDLE_ID` (по умолчанию `us.snapdance.app`).

## Проверка сборки

GitHub Actions (`.github/workflows/ios.yml`) собирает приложение для симулятора на каждый пуш в `ios/`.
