# SnapDance для iOS

Нативное приложение-обёртка для https://snapdance.us (SwiftUI + WKWebView, iOS 16+).

## Как открыть и запустить

1. Распакуйте архив и дважды кликните `SnapDance.xcodeproj`.
2. Слева выберите проект **SnapDance** → цель **SnapDance** → вкладка **Signing & Capabilities** → в поле **Team** выберите свой Apple ID / команду разработчика.
   Если Xcode ругается на Bundle Identifier — поменяйте `us.snapdance.app` на любой свой уникальный (например, `com.вашеимя.snapdance`).
3. Сверху выберите симулятор или подключённый iPhone и нажмите ▶︎ (Cmd+R).

## Что умеет

- Открывает сайт на весь экран, тёмная тема, иконка в стиле сайта.
- Загрузка фото и роликов-образцов из галереи или с камеры.
- «⬇ Скачать видео» → меню «Поделиться»: «Сохранить видео» в Фото, TikTok, Instagram, AirDrop.
- Оплата Stripe открывается внутри приложения, после оплаты возвращает на сайт.
- Код `SD-…`, рубины и вход сохраняются между запусками.
- Ссылки на TikTok/Instagram/YouTube открываются в их приложениях.
- Свайп назад, обновление потягиванием вниз, экран «Нет соединения» с кнопкой «Повторить».
- Сервер видит в User-Agent метку `SnapDanceApp/1.0` — по ней можно менять поведение сайта для приложения.

## Настройки

Всё в `SnapDance/ContentView.swift`, блок `SDConfig`: адрес сайта, домены, которые открываются внутри приложения, и метка User-Agent.
